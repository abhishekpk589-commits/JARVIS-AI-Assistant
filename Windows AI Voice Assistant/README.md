Windows AI Voice Assistant (JARVIS)

A browser-based voice assistant built with HTML, CSS, and JavaScript. It uses the browser's Web Speech APIs for speech recognition and speech synthesis.
Features
- Voice input through the microphone
- Spoken responses using browser speech synthesis
- Greeting based on the time of day
- Open Google, YouTube, and Facebook by voice command
- Search the web and Wikipedia by voice command
- Tell the current time and date
- Open the calculator
  
Technologies Used
- HTML
- CSS
- JavaScript
- Web Speech API
- Font Awesome
  
Project Files
- index.html — application page
- style.css — page styling
- script.js — voice assistant functionality
- JARVIS IMAGE.jpg — JARVIS visual
  
Run Locally
This is a static browser project. Electron and npm install are not required.
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open index.html directly in a browser, or use the VS Code Live Server extension.
4. Allow microphone access when the browser asks for permission.
Microphone access generally requires localhost or an HTTPS website. Speech recognition support depends on the browser.
